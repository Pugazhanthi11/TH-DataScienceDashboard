# Data Science Dashboard

This focuses on creating a simple data science dashboard using Streamlit.

The dashboard presents information from the COVID-19 dataset used throughout the internship tasks. It includes a dataset preview, summary statistics, visualizations, and engineered features.

## Tools Used

- Python
- Pandas
- Streamlit

## Files

- dashboard.py
- featured_covid_data.csv

## Features

- Dataset Preview
- Summary Statistics
- Top 10 Countries by Cases
- Feature Engineering Results
